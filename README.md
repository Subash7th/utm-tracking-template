
# UTM Tracking Template

A simple template for creating consistent UTM tracking links for digital marketing campaigns.

## Download the UTM Template

[Download the UTM Tracking CSV Template](utm-links-template.csv)

## Parameters

| Parameter | Example |
|---|---|
| utm_source | linkedin |
| utm_medium | social |
| utm_campaign | analytics_guide_launch |
| utm_content | feed_post |

## Example URL

https://example.com/guide/?utm_source=linkedin&utm_medium=social&utm_campaign=analytics_guide_launch&utm_content=feed_post

## Naming Rules

- Use lowercase letters.
- Use underscores between words.
- Keep campaign names consistent.
- Avoid spaces and unclear abbreviations.
- Test links before publishing.
